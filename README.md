# OLLAMA — 4 часа: Практические задания

## Описание
Серия практических заданий по работе с Ollama — локальным LLM-модель, REST API, Python-интеграция, RAG, Docker.

## Задания

### Задание 1: Установка Ollama и запуск первой модели
Освоить базовые навыки установки Ollama и работы с моделями через командную строку.

**Шаги:**
1. Установите Ollama с [ollama.com](https://ollama.com)
2. Скачайте модель: `ollama pull llama3.2`
3. Запустите сеанс: `ollama run llama3.2`
4. Задайте вопросы модели
5. Выйдите: `Ctrl+D` или `/bye`

---

### Задание 2: Генерация текста через REST API
Взаимодействие с Ollama через HTTP-запросы.

**Пример curl:**
```bash
curl http://localhost:11434/api/generate -d '{
  "model": "llama3.2",
  "prompt": "Напиши короткое стихотворение о программировании",
  "stream": false
}'
```

---

### Задание 3: Чат с моделью через API
Работа с чат-интерфейсом Ollama и управление историей сообщений.

**Пример:**
```bash
curl http://localhost:11434/api/chat -d '{
  "model": "llama3.2",
  "messages": [
    {"role": "user", "content": "Привет! Как тебя зовут?"}
  ],
  "stream": false
}'
```

- Ollama (https://ollama.com)
- Python 3.10+
- Библиотеки: `ollama`, `sentence-transformers`, `requests`
- Docker (для задания 10)
